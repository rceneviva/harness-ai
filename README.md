# harness-ai

Materiais da oficina **“Construindo o Harness de IA: Controle e Reprodutibilidade para Agentes Autônomos em Ciência de Dados”**, de Ricardo Ceneviva (UFABC) e Anderson Borba (Mackenzie).

## Estrutura do repositório

- `aula_harness_ia.pdf` — deck da aula teórica.
- `colab-inicial/` — notebook, replay e dados do exercício usados no laboratório.
- `colab-solucao/` — solução docente e arquivos de referência publicados para consulta e reprodução.
- `exemplos/harness-minimo/` — arquivos didáticos que ilustram instruções, workflow e replay de um harness mínimo.
- `exemplos/governanca/` — exemplos reais de documentação de governança para projetos de Data Science e agentes.

## Exemplos adicionais para Q&A

Os arquivos em `exemplos/` ampliam o caso único da oficina e podem ser usados para discutir como um harness se apoia em camadas diferentes de documentação e controle.

### Harness mínimo

- `AGENTS.md` — exemplo de instruções persistentes.
- `workflow.md` — exemplo de mapa humano do processo.
- `replay.json` — exemplo de sequência preparada de ações.

### Governança

- `GLOBAL-RULES.md` — exemplo de princípios transversais para execução simples, verificável e auditável.
- `RULES.md` — exemplo de regras de projeto para Data Science, com hierarquia de fontes, validação, segurança, tracing e handoff.

**Importante:** os arquivos em `exemplos/` são materiais pedagógicos e não devem ser interpretados como instruções normativas ativas deste repositório.

## Uso

O repositório foi organizado para apoiar a aula, o laboratório e a discussão de exemplos práticos durante a sessão de perguntas e respostas.
